Current status: demo data

This preview build runs entirely on a bundled demo dataset. Mission names, providers, vehicles and sites refer to real organisations so the layouts can be judged realistically. The specific launches, schedules, outcomes and historical statistics are illustrative, and the historical series is synthetic. Live data integration begins in Phase 2.

Measured, derived and estimated

Measured

Values reported by a source, such as scheduled times, statuses and outcomes. Each one keeps the source's identifier.

Derived

Values computed by MissionWatch from measured data, such as launch counts, success shares and schedule shifts between snapshots.

Estimated or illustrative

Generic milestone timings, illustrative trajectories and any model output. These are always labelled, and they are never presented as mission-specific fact.

Models and predictions

No predictive model is deployed. Delay-risk estimates (FR-11) will only appear after a model has been trained on stored schedule snapshots, evaluated on chronologically later data and compared with a simple baseline. Each prediction will show the model version, the training period and the evaluation results. If the data turns out to be insufficient, MissionWatch will publish historical analytics only.

Explanations such as SHAP describe how the model behaves. They do not establish real-world causes of a postponement.
